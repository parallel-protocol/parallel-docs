# Parallel Governance Proposal (PGP)

## 1. Writing a PGP

PGP are about common governance proposals, especially the ones related to the treasury of the protocol and the DAO organization.

* **The PGP would concern but wouldn’t be limited to:**
  * Treasury allocation strategy & budgets
  * Liquidity mining votes
  * Grant program if any
  * Contributors/Dao committees rewards
  * Long term partnerships (i.e Dao Swaps)

## 2. Submission of Proposal

PGP concern the protocol treasury directly, which is why it might be best to define more conservative parameters than PIR ones:

* Admin: DAO Multisig
* Quorum: 200,000 sPRL (ParaBoost)
* Voting Duration: 7 days
