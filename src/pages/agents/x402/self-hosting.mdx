# Self-host the facilitator

The Parallel x402 facilitator is open source and MIT licensed. You can run your own instance and point your middleware at it instead of the hosted facilitator — your traffic is never gated by Cooper Labs.

```ts
paymentMiddleware({
  facilitator: { url: "https://your-facilitator.example.com" },
  routes: { /* ... */ },
});
```

:::info
Full self-hosting instructions — the facilitator repository, container image, and required environment (RPC endpoints, relayer wallet, database) — are being finalized and will be published here. Need them now? [Ask in #builders on Discord](https://discord.gg/vuuAVAxpcF) and we'll get you set up.
:::
