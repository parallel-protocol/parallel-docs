Your server moves in minutes. Agents pay with the Parallel client, @parallel-protocol/x402-fetch, and Coinbase x402 clients can pay your metered routes on Base in USDC."

    question: "What happens if the facilitator goes down?",
    answer: "Payments fail safe: if the facilitator is unreachable, nothing settles. Signed authorizations simply expire and no funds move. If only a settle's answer is lost, the SDK retries the settle once, which is safe since the facilitator answers a repeated settle with its recorded outcome. If that fails too, the agent gets a 402 saying the payment may still settle, and should check with the merchant before paying again. A public status page for the hosted instance is being set up. Meanwhile, the facilitator's GET /health reports whether its chain nodes, database and cache answer."
