# PRL Contract Addresses

The PRL governance token is deployed on 6 chains: Ethereum, where the canonical ERC-20 lives, and Base, Arbitrum, Optimism, Polygon PoS and Sonic, which each hold a `PeripheralPRL` OFT. This page also lists PRL tokenomics contracts on Avalanche and HyperEVM, and a deprecated migration contract on Fantom; none of those three carries the token itself.

For a one-page summary of key facts, contracts and integration links, see the [PRL factsheet](/resources/factsheets/prl).
