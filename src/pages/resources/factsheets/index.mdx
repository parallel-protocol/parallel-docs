# Token Factsheets

Each factsheet is a one-screen summary of a Parallel token that an exchange listing team, an integrator or an analyst can read in two minutes: key facts in a table, how the token works, what backs it, where to get it and how to integrate it. All three sheets share the same layout so they can be compared side by side. Every figure links back to the page of these docs it comes from.
